# 中华绒螯蟹基因组数据库系统部署文档

## 项目概述
- **项目名称**: 中华绒螯蟹基因组数据库系统
- **部署环境**: Windows 11 + WSL2 Ubuntu 22.04
- **外网访问**: http://mittencrab.nat100.top (通过natapp内网穿透)

## 系统架构

### 部署分布
```
Windows 宿主机:
├── MySQL 数据库 (端口3306)
└── natapp 内网穿透

WSL2 Ubuntu:
├── 前端 Vue3 + Nginx (端口80)
├── 后端 Spring Boot (端口3002) 
├── 文件服务 Node.js (端口3003)
└── R 环境 (/usr/bin/R)
```

### 网络配置
- WSL访问Windows MySQL: `172.20.112.1:3306`
- 外网域名: `mittencrab.nat100.top`
- Nginx反向代理: `/api/` → `localhost:3002`, `/file-api/` → `localhost:3003`

## 技术栈详情

### 前端
- **框架**: Vue 3.3.4 + Element Plus 2.3.8
- **构建工具**: Vue CLI 5.0.0
- **静态文件路径**: `/mnt/d/workspace/demo/crab-frontend-v3/dist`

### 后端
- **框架**: Spring Boot 2.6.13 + Java 17
- **构建工具**: Maven
- **JAR文件**: `target/crdb-0.0.1-SNAPSHOT.jar`
- **配置文件**: `src/main/resources/application.yaml`

### 文件服务
- **环境**: Node.js + Express
- **文件**: `server/file-server.js`
- **下载目录**: `server/downloads`

### 数据库
- **版本**: MySQL 8.x
- **数据库名**: `crab_database`
- **连接地址**: `172.20.112.1:3306`

## 完整部署步骤

### 1. 数据库准备 (Windows)
```powershell
# 确保MySQL服务运行
net start MySQL

# 创建数据库和用户
mysql -u root -p
CREATE DATABASE crab_database;
# 导入数据...
```

### 2. 后端部署 (WSL2)
```bash
cd /mnt/d/workspace/demo

# 构建后端项目
mvn clean package -DskipTests

# 验证JAR文件生成
ls -la target/crdb-0.0.1-SNAPSHOT.jar
```

### 3. 前端构建 (WSL2)
```bash
cd /mnt/d/workspace/demo/crab-frontend-v3

# 安装依赖
npm install

# 构建生产版本
npm run build

# 验证构建结果
ls -la dist/
```

### 4. Nginx配置 (WSL2)
```bash
# 检查Nginx配置
sudo nginx -t

# 重新加载配置
sudo systemctl reload nginx

# 确保Nginx开机启动
sudo systemctl enable nginx
```

### 5. 服务启动

使用部署脚本启动所有服务：
```bash
cd /mnt/d/workspace/demo

# 给脚本执行权限
chmod +x deploy/*.sh

# 启动所有服务
./deploy/start.sh
```

### 6. 验证部署

#### 检查服务状态
```bash
./deploy/status.sh
```

#### 验证各服务
1. **后端API**: http://localhost:3002
2. **文件服务**: http://localhost:3003
3. **前端页面**: http://localhost
4. **外网访问**: http://mittencrab.nat100.top (需启动natapp)

### 7. 启动natapp (Windows)
在Windows环境下启动natapp客户端，监听WSL2的80端口。

## 重要配置文件

### application.yaml (后端配置)
```yaml
server:
  port: 3002
  address: 0.0.0.0

spring:
  datasource:
    url: jdbc:mysql://172.20.112.1:3306/crab_database
    username: root
    password: bgs2281037

r:
  bin:
    path: /usr/bin
  scripts:
    path: /mnt/d/workspace/demo/src/main/resources/r_scripts
```

### Nginx配置 (/etc/nginx/sites-available/default)
```nginx
server {
    listen 80;
    server_name localhost;
    root /mnt/d/workspace/demo/crab-frontend-v3/dist;
    index index.html;
    
    # API代理
    location /api/ {
        proxy_pass http://localhost:3002/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_connect_timeout 300;
        proxy_send_timeout 300;
        proxy_read_timeout 300;
    }
    
    # 文件服务代理
    location /file-api/ {
        proxy_pass http://localhost:3003;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_connect_timeout 1200;
        proxy_send_timeout 1200;
        proxy_read_timeout 1200;
    }
    
    # 前端路由
    location / {
        try_files $uri /index.html;
    }
}
```

## 常见问题

### 1. 数据库连接失败
- 检查MySQL服务是否启动
- 验证WSL可以访问Windows的IP `172.20.112.1`
- 确认防火墙设置

### 2. 前端页面无法访问
- 检查Nginx服务状态: `sudo systemctl status nginx`
- 验证前端构建是否成功: `ls -la crab-frontend-v3/dist/`
- 检查Nginx配置: `sudo nginx -t`

### 3. API请求失败
- 确认后端服务运行状态
- 检查端口占用: `netstat -tlnp | grep 3002`
- 查看后端日志: `tail -f deploy/logs/backend.log`

### 4. 文件下载功能异常
- 检查文件服务状态
- 确认下载目录权限: `ls -la server/downloads/`
- 查看文件服务日志: `tail -f deploy/logs/file-server.log`
